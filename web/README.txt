Esperanza's Drum Kit - run it on your computer

Mac:      double-click "Start (Mac).command" (first time: right-click > Open).
Windows:  double-click "Start (Windows).bat".
Linux:    run ./start.sh

It opens http://localhost:8748 in your browser. Keep the little window open while you work.
Python 3 is needed for the launcher; without it the page opens directly, which works in
Chrome and Edge but not in Safari (Safari will not start the audio engine from a file).
